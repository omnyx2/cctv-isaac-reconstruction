The real memory limit. CPU, GPU, Isaac Sim and the VLM all share it.

2 crashes

qwen3-vl 32B and qwen2.5vl 72B ran out of memory. We do not run 72B or bigger here.

45 → 19 GB

The same q4 model, once we told it to remember 8,192 tokens instead of 262,144.

DGX Spark shares one memory between CPU and GPU, and the container's real limit is about 117 GB, shared with other programs. Twice during testing a model used it up and the whole container was killed: desktop, terminals, everything. So llama3.2-vision 90B and llama4 scout were never tried. Hidden memory hog: Ollama reserves room for the model's full context. qwen3-vl allows 262,144 tokens, which took 45 GB. One picture plus a question plus an answer fits in 8,192 tokens, and then the model takes 19 GB. Rule of thumb: the model plus Isaac Sim must leave plenty of memory free.
