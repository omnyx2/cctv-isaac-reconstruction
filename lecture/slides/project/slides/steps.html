ScriptWhat it does

Clever trick: the dataset is one 5.6 GB zip. We read only its table of contents and download just the photos we need, like borrowing one book instead of the whole library.

Step 0 installs nothing. Step 2 puts packages only into .pydeps inside the project, so Isaac Sim stays untouched. Real bug we hit: Isaac Sim's OpenCV is a headless build that cannot open windows, so we add a window-capable one. Step 3 uses HTTP Range requests through remote_zip.py. If a download stops, run it again.
