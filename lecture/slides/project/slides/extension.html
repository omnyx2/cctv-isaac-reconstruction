Detective story: 3 bugs before it worked on Linux

The three bugs: 1) the YOLO helper started the system Python, because inside Isaac Sim sys.executable points at /usr/bin/python3; 2) No module named numpy, because a new process copies only sys.path; 3) No module named ultralytics, because Isaac Sim ignores PYTHONPATH unless we pass Py_IgnoreEnvironmentFlag=false. Lesson: when a program starts another program, the second one does not automatically know everything the first one knows.
